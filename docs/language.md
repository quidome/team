# Language

The words that all documents, code and conversations about this product use. Only the Vision
stage adds, changes or removes words. Define meaning, not mechanics: no flags, paths or formats.

| Term | Meaning | Use / do not use |
|------|---------|------------------|
| coordinator | The one person who uses the tool and changes its data. Runs one team. | Not "admin", not "user" when the coordinator is meant. |
| team | The youth team the coordinator runs. | Say "other club team" for the club's other teams. |
| club | The sports club the team belongs to. | |
| player | A member of the team. Has a first and a last name. | Not "member", not "child" in the product. |
| game | One match on the schedule, with a date, start time, place, home team and away team. | Not "match", not "fixture". |
| home game / away game | A game of the team in the club's own hall / at another club. | |
| game list | The federation's list of all games of the club, read by the tool. | Not "feed" in user-facing text. |
| training | A training session of the team. | |
| attendance | Whether a player was at a training. | |
| duty | A task a player must do for a game: drive, jury or referee. | Not "task" for these. |
| drive | The duty to drive players to an away game. | |
| jury / referee | The duty to fill a jury or referee place at another club game. | |
| duty total | How many duties a player has done. Shows that the work is shared fairly. | |
| message | Text the tool produces for the coordinator to copy into the chat. | The tool never "sends". |
| referee committee | The club group that wants to know which players do which jury and referee duties. | |
