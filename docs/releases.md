# Releases

What each release brought to the user, newest first. One line for each release; the details
of each feature are in the product documents (`docs/product/`). Written when a release is made;
the steps are in `README.md`.

| Version | Date | What changed for the user |
|---------|------|---------------------------|
| v0.12.0 | 2026-11-11 | One panel "Administration" at the top of the page of a training and a game: each mark (Checked, Cancelled, Not played, The drives count, Schedule entered) is a row with its state (○ / ✓) and one button ("Mark as checked", "Mark as entered", "Count the drives", or "Undo"); orange only for the next step. Below "Not checked" an away game shows its drivers, and a game without any answer warns that the check makes every player absent. New words "Mark as not played" and "Mark answers as checked". |
| v0.11.2 | 2026-11-11 | The page of a game: a table or referee place that names a club team that plays that game shows "This team plays this game."; the place still saves. |
| v0.11.1 | 2026-11-11 | The report: a tap anywhere on a row opens or closes the details of the player, and the details no longer repeat the name. |
| v0.11.0 | 2026-11-11 | A quieter start page: the team and today's date, the open items as rows, then one list of the coming events grouped by date (games of the team stand out, duty games have a blue bar, done events are lighter, "Home game against" / "Away game at"); no "Last", except the duty games of the last date with duties; "Message of the week" and the committee message only when they have something (the committee message is always on "Duties"); Team, Players and Settings under "More", "Change club or team" on Settings. |
| v0.10.0 | 2026-11-09 | The report: one page for the current season with, for each player, trainings and games as a percentage and drive, table and referee as done + planned; the players who left below it; a line with the training days not opened and the games not checked; the details of a player on a tap (absences valid and not valid, duties done by or for another player, and not done); "Copy" for each column as a Dutch text for the chat. |
| v0.9.0 | 2026-11-08 | Attendance at games, release 2: "Not played" for a game (it counts nothing, with "The drivers drove"); from the start time "There" and "Absent", "Checked" with "Undo check", the open item "games not checked" from 4 Nov, and "· Checked" on the rows; duty places offer "Someone else" and "Nobody" and count as done from the start time; checked games in the totals on "Attendance". |
| v0.8.0 | 2026-11-04 | Attendance at games, release 1: who comes to each game of the team (coming, not coming with a reason, no answer, extra players, the count on the rows), and the warnings in time: too few players in the last 3 days, a driver who is not coming, and answers from before a move with "Answers checked". |
| v0.7.0 | 2026-10-31 | The message of the week (replaces the message for the next game), the committee message, and the duty overviews (all coming drives, or all coming table and referee places). Duties is complete. |
| v0.6.0 | 2026-10-29 | The message for the next game: the Dutch text to copy for the team and the parents. |
| v0.5.0 | 2026-10-28 | Duties, part 1: the page of each game, the referee committee's schedule copied into the tool, the drivers of away games, players on the duty places of the team, and the duty totals on the page "Duties". |
| v0.4.0 | 2026-10-25 | The start page with the open items, the last training and the events of this week and next week; the page "Season"; "Checked" for the attendance of a training. |
| v0.3.3 | 2026-10-18 | A new game that leaves the game list and comes back before it is seen stays new; a page loads its data on a tap, not on hover. |
| v0.3.2 | 2026-10-18 | The player names are stored only encrypted (release 2 of 2). |
| v0.3.1 | 2026-10-18 | The player names are stored encrypted (release 1 of 2): a copy of the database or a backup does not show who the players are. |
| v0.3.0 | 2026-10-18 | Attendance at training: the players and the team of each season with their roles, weekly trainings and reasons, opening a training and marking who is absent and why, and the totals for each player in a season. |
| v0.2.0 | 2026-10-14 | Games from the game list: choose the club and the team for each season, read the games on a tap and every night, the schedule, and the list of changes. |
| v0.1.1 | 2026-10-11 | No change for the user: the same base, built and released by the new pipeline. |
| v0.1.0 | 2026-10-11 | The base of the new product: login through Pocket ID, a start page, and a sample schedule with example games. |
