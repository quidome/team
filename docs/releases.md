# Releases

What each release brought to the user, newest first. One line for each release; the details
of each feature are in the product documents (`docs/product/`). Written when a release is made;
the steps are in `README.md`.

| Version | Date | What changed for the user |
|---------|------|---------------------------|
| v0.7.0 | 2026-10-31 | The message of the week (replaces the message for the next game), the committee message, and the duty overviews (all coming drives, or all coming table and referee places). Duties is complete. |
| v0.6.0 | 2026-10-29 | The message for the next game: the Dutch text to copy for the team and the parents. |
| v0.5.0 | 2026-10-28 | Duties, part 1: the page of each game, the referee committee's schedule copied into the tool, the drivers of away games, players on the duty places of the team, and the duty totals on the page "Duties". |
| v0.4.0 | 2026-10-25 | The start page with the open items, the last training and the events of this week and next week; the page "Season"; "Checked" for the attendance of a training. |
| v0.3.3 | 2026-10-18 | A new game that leaves the game list and comes back before it is seen stays new; a page loads its data on a tap, not on hover. |
| v0.3.2 | 2026-10-18 | The player names are stored only encrypted (release 2 of 2). |
| v0.3.1 | 2026-10-18 | The player names are stored encrypted (release 1 of 2): a copy of the database or a backup does not show who the players are. |
| v0.3.0 | 2026-10-18 | Attendance at training: the players and the team of each season with their roles, weekly trainings and reasons, opening a training and marking who is absent and why, and the totals for each player in a season. |
| v0.2.0 | 2026-10-14 | Games from the game list: choose the club and the team for each season, read the games on a tap and every night, the schedule, and the list of changes. |
| v0.1.1 | 2026-10-11 | No change for the user: the same base, built and released by the new pipeline. |
| v0.1.0 | 2026-10-11 | The base of the new product: login through Pocket ID, a start page, and a sample schedule with example games. |
