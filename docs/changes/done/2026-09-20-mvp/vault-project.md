## What this project is

This project folder contains the knowledge for the team application. The product details are still being discovered; this file intentionally does not invent requirements or describe an application that has not yet been defined.

## Current phase
**MVP complete; early post-MVP refinement.**

The [[planning/mvp-implementation-plan|MVP Implementation Plan]]'s seven phases (foundation/auth, core domain, program/event management, participation, duties/transport, WhatsApp drafts, imports, reports/audit/hardening) are done. Production deployment is tracked outside this repository.

Work since that completion milestone (2026-09-20) has continued in the source repository ahead of this vault: the Program navigation area and terminology were renamed to Events, games can now reference external opponents (tracked separately from own teams) grouped into season halves (H1/H2), and a consolidated Admin screen replaced the former Settings page with modal-based create/edit for seasons, teams, and locations. These are implementation-driven additions — see the note in the implementation plan — and are not yet reconciled into the product notes below.
